## ✨ Features
* **Role-based Access:** Different views for Admin/Teachers and Students.
* **Class Management:** Teachers can create and view scheduled classes.
* **Student Enrollment:** Students can browse available classes and enroll.
* **Offline First:** Data is saved locally in the browser using Dexie.js (No backend API required).
* **Responsive UI:** Styled with Tailwind CSS for a modern look.

## 🛠️ Tech Stack
* **Frontend:** HTML5, Tailwind CSS
* **Logic:** Vanilla JavaScript (ES6+)
* **Database:** Dexie.js (Wrapper for IndexedDB)
